# ahotan.py (AHONOKO TANK in python)

昔懐かしのPCゲームを今のパソコンに移植しようシリーズGames in the atticその4

Pythonで書かれています。

ahotan.pyは自作のライブラリ、supertextを使っています。

ahotanw.pyはsupertextを使っていません。ワイヤーフレーム版です。

両方共、ahotan.mapをカレントディレクトリに置いて起動してください。

白、黒のタンクを、右と左に分けて二人でプレイする対戦型ゲームです。

弾はタンクの向きに移動するので、タンクで弾を遠隔操作し、相手を砲撃してください。

先に3ポイント取ったほうが勝ちです。

キー操作：左プレイヤーは、's'で左、'f'で右、'e'で上、'c'で下、'z'で発射です。

          右プレイヤーは、'4'で左、'6'で右、'8'で上、'2'で下、'0'で発射です。

          'q'で、ゲームから抜けます。

# English:

A series porting classic PC games to modern computers: Games in the Attic, Part 4

ahotan.py uses a custom library, supertext.

ahotanw.py does not use supertext. It is a wireframe version.

For both, please place ahotan.map in the current directory and run the program.

This is a two-player competitive game where players are divided into left and right sides, each controlling a white and a black tank.

The projectiles move in the direction of the tank, so remotely control the projectiles from your tank and bombard your opponent.

The first player to reach 3 points wins.

Key Controls: Left player: 's' for left, 'f' for right, 'e' for up, 'c' for down, 'z' for fire.

Right player: '4' for left, '6' for right, '8' for up, '2' for down, '0' for fire.

Press 'q' to exit the game.
